# Airbnb Data Analysis

## Overview
Exploratory data analysis of Airbnb listings in New York City,
completed as part of the VOIS for Tech Data Analytics Program
structured curriculum - guided analysis with mentor support.

## Objective
Analyse listing distribution, pricing patterns, and room type 
variations across NYC boroughs.

## Tools Used
- Python (pandas, numpy, matplotlib, seaborn)
- Google Colab

## Dataset
~102,000 listings | Columns include borough, room type, 
price, number of reviews, availability, host information

## Key Findings
- Manhattan and Brooklyn have the highest listing counts
- Entire home/apt is the most common room type (53,000+)
- Average and median price are nearly identical (~$625)
  suggesting relatively even price distribution
- Staten Island has the fewest listings (946)
